# Srajdrone
Standalone 3D browser arcade game. Keep it separate from Ore Frontier.
Use TypeScript and Three.js. Run npm install, npm test, npm run build for relevant changes.
Browser-playtest input, cameras, target marking, collisions and the recon/FPV loop.
Keep QA artifacts under ignored output/playwright/. Document actual tests and limitations.
Use original or appropriately licensed assets. Do not import Google Maps imagery or traced geometry.
